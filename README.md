#  Water Raindrop Detection Using NodeMCU with KiwisIoT

## 📌 About the Project

Water Raindrop Detection Using NodeMCU with KiwisIoT is an IoT-based project designed to detect rainfall and monitor raindrop intensity in real time.

Using a NodeMCU ESP8266 microcontroller and a rain sensor module, the system detects water droplets on the sensor surface and identifies rainfall conditions.

The collected sensor data is transmitted through Wi-Fi to the KiwisIoT platform, where users can visualize and monitor rain detection status and sensor readings through an online dashboard from anywhere.

This project demonstrates how IoT technology can support weather monitoring, smart irrigation applications, and automated rain detection systems.
